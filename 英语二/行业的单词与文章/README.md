# 行业的单词与文章

这套资料把 10 个常见行业拆成了 10 份独立 Markdown 文件。每份文件都包含：

- 行业核心词汇
- 常见物件与设备命名
- 常见产品与服务命名
- 1 篇对应主题英文文章

文件目录：

- `01-科技与互联网.md`
- `02-金融与投资.md`
- `03-医疗健康.md`
- `04-教育行业.md`
- `05-制造业.md`
- `06-市场营销.md`
- `07-物流与电商.md`
- `08-能源与环保.md`
- `09-旅游与酒店.md`
- `10-农业与食品.md`

建议用法：

1. 先背行业核心词，再背该行业常见物件和产品名称。
2. 对照音标朗读一遍，再做英汉互译。
3. 读完文章后，用其中 8-10 个词写一个小段落。
4. 优先记住高频名词，因为阅读和写作里最常卡住的就是具体事物的命名。
