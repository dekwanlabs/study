## 三、复习总原则

### 3.1 数学二不是“范围大”，而是“主干硬”

数学二最容易让人吃亏的点，不是知识特别散，而是：

- 极限、导数、积分这三段前后连得很紧；
- 线代虽然分值不算最高，但概念一乱就整章崩；
- 计算量大，步骤一错后面容易全错。

### 3.2 在职备考最怕两件事

- 只听课不动笔；
- 只刷题不回头。

所以你的每一章都按这套闭环走：

1. 先看定义和公式；
2. 再看标准题型；
3. 然后自己完整写两三道题；
4. 最后复盘“我为什么卡住”。

### 3.3 一轮阶段的目标

一轮不要追求“难题都会”，你的目标应该是：

- 选择填空的常规题能识别题型；
- 大题能写出标准步骤；
- 知道什么时候用等价无穷小、洛必达、换元、分部、初等变换、秩、特征值；
- 计算错误逐步减少。

## 第一篇：高等数学

## 第一章 函数、极限、连续

### 1.1 这一章在解决什么

这章解决的是数学二的“语言问题”。后面的导数、积分、微分方程，都是建立在这里的。

你至少要搞清楚四件事：

- 函数到底是什么，定义域怎么找；
- 极限什么时候存在，怎么算；
- 无穷小和无穷大怎么比较；
- 连续、间断点到底怎么判断。

### 1.2 核心知识

#### 1.2.1 函数基础

- 会判断定义域，尤其是根号、分母、对数、反三角函数一起出现时；
- 会看函数的单调性、奇偶性、周期性、有界性；
- 要认识复合函数、反函数、分段函数、隐函数。

#### 1.2.2 两个重要极限

必须背熟并会变形：

- $\lim\limits_{x \to 0}\dfrac{\sin x}{x} = 1$
- $\lim\limits_{x \to \infty}\left(1+\dfrac{1}{x}\right)^x = e$

常见变形也要会：

- $\lim\limits_{x \to 0}\dfrac{\tan x}{x} = 1$
- $\lim\limits_{x \to 0}\dfrac{1-\cos x}{x^2} = \dfrac{1}{2}$
- $\lim\limits_{x \to 0}\dfrac{\arcsin x}{x} = 1$
- $\lim\limits_{x \to 0}\dfrac{\arctan x}{x} = 1$

#### 1.2.3 常用等价无穷小

当 $x \to 0$ 时，常见等价无穷小是：

- $\sin x \sim x$
- $\tan x \sim x$
- $1-\cos x \sim \dfrac{x^2}{2}$
- $e^x - 1 \sim x$
- $\ln(1+x) \sim x$
- $(1+x)^a - 1 \sim ax$
- $\arcsin x \sim x$
- $\arctan x \sim x$

最重要的提醒：

- 等价无穷小主要用于乘除，不能不经变形就直接在加减里乱换。

#### 1.2.4 极限的常见方法

先后顺序建议固定：

1. 直接代入；
2. 因式分解、通分、分子分母有理化；
3. 用重要极限和等价无穷小；
4. 用夹逼准则；
5. 满足条件时再用洛必达法则。

#### 1.2.5 连续与间断

要会判断：

- 某点连续：左右极限存在且相等，并且等于函数值；
- 可去间断点；
- 跳跃间断点；
- 无穷间断点。

闭区间连续函数的几个性质也要记住：

- 有界性；
- 最值性；
- 介值性。

### 1.3 高频题型

- 求极限；
- 判断分段函数在某点是否连续；
- 比较无穷小阶；
- 求含参数的连续条件。

### 1.4 易错点

- 把等价无穷小生搬硬套到加减结构里；
- 左右极限不相等，却误以为函数不连续只是“可去”；
- 只会看公式，不会先判断定义域；
- 洛必达法则不先判断是不是 $0/0$ 或 $\infty/\infty$。

### 1.5 过关标准

学完这一章，你至少要能做到：

- 独立算出常规极限；
- 独立判断分段函数的连续性；
- 看到 $\sin x$、$\ln(1+x)$、$e^x-1$ 这类结构，能立刻想到等价无穷小。

## 第二章 一元函数微分学

### 2.1 这一章在解决什么

导数是考研高数最核心的工具。你后面做极值、单调性、最值、曲线分析、微分方程，几乎都要靠它。

### 2.2 核心知识

#### 2.2.1 导数和微分

你要理解：

- 导数的定义；
- 导数的几何意义：切线斜率；
- 可导一定连续，但连续不一定可导；
- 微分本质上是线性主部。

#### 2.2.2 基本求导公式

这些必须能默写：

- $(x^a)' = ax^{a-1}$
- $(e^x)' = e^x$
- $(a^x)' = a^x \ln a$
- $(\ln x)' = \dfrac{1}{x}$
- $(\log_a x)' = \dfrac{1}{x \ln a}$
- $(\sin x)' = \cos x$
- $(\cos x)' = -\sin x$
- $(\tan x)' = \sec^2 x$
- $(\arcsin x)' = \dfrac{1}{\sqrt{1-x^2}}$
- $(\arctan x)' = \dfrac{1}{1+x^2}$

#### 2.2.3 求导法则

必须熟练：

- 和差法则；
- 乘法法则；
- 商法则；
- 复合函数求导；
- 反函数求导；
- 隐函数求导；
- 参数方程确定的函数求导：$\dfrac{dy}{dx} = \dfrac{dy/dt}{dx/dt}$。

#### 2.2.4 高阶导数

高阶导数常见考法：

- 连续求导；
- 由递推结构找规律；
- 结合莱布尼茨公式或常见函数结构求第 $n$ 阶导数。

### 2.3 高频题型

- 复合函数求导；
- 隐函数求导；
- 参数方程求导；
- 切线、法线方程；
- 高阶导数。

### 2.4 易错点

- 漏掉链式法则里的“里层导数”；
- 看到隐函数直接乱移项，不先两边同时对自变量求导；
- 参数方程求导时忘记除以 $dx/dt$；
- 对数求导时忘记绝对值或定义域。

### 2.5 过关标准

- 常见初等函数导数能直接写；
- 复合、隐函数、参数方程三类求导题能独立完成；
- 切线和法线题不再混淆。

## 第三章 中值定理、洛必达法则与导数应用

### 3.1 这一章在解决什么

这一章决定你能不能把“会求导”变成“会做题”。很多大题真正考的不是公式，而是你会不会利用导数分析函数。

### 3.2 核心知识

#### 3.2.1 微分中值定理

重点掌握：

- 罗尔定理；
- 拉格朗日中值定理；
- 柯西中值定理；
- 泰勒定理。

考试里最常用的是：

- 用拉格朗日中值定理证明不等式或讨论单调性；
- 用泰勒展开处理高阶无穷小和复杂极限。

#### 3.2.2 常见泰勒展开

在 $x \to 0$ 时，下面这些展开非常常用：

- $e^x = 1 + x + \dfrac{x^2}{2} + o(x^2)$
- $\ln(1+x) = x - \dfrac{x^2}{2} + o(x^2)$
- $\sin x = x - \dfrac{x^3}{6} + o(x^3)$
- $\cos x = 1 - \dfrac{x^2}{2} + o(x^2)$
- $(1+x)^a = 1 + ax + \dfrac{a(a-1)}{2}x^2 + o(x^2)$

#### 3.2.3 洛必达法则

适用场景：

- 先判断是否属于 $0/0$ 或 $\infty/\infty$ 型；
- 再考虑能不能用洛必达；
- 一次不够时可以继续，但每次都要重新判断。

#### 3.2.4 导数的应用

这一部分是高频中的高频：

- 单调区间；
- 极值；
- 最值；
- 凹凸性；
- 拐点；
- 渐近线；
- 函数图像描绘。

求单调性和极值的标准路线要固定：

1. 求定义域；
2. 求导数；
3. 找驻点和不可导点；
4. 划分区间判断导数符号；
5. 写结论。

斜渐近线常用公式：

- $k = \lim\limits_{x \to \infty}\dfrac{f(x)}{x}$
- $b = \lim\limits_{x \to \infty}(f(x)-kx)$

### 3.3 高频题型

- 用洛必达法则求极限；
- 求函数的单调区间、极值、最值；
- 求渐近线；
- 证明不等式；
- 画函数大致图像。

### 3.4 易错点

- 洛必达法则和等价无穷小混用时顺序混乱；
- 极值点和最值点不区分；
- 只算出驻点，不判断左右符号；
- 斜渐近线只算 $k$，漏掉 $b$。

### 3.5 过关标准

- 遇到函数性质题，能熟练走“定义域-求导-符号表-结论”流程；
- 泰勒展开至少能记住最常考的五个；
- 极限题里知道什么时候该用等价，什么时候该用洛必达。

## 第四章 一元函数积分学：不定积分

### 4.1 这一章在解决什么

不定积分本质上是“反过来找原函数”。这一章会直接影响后面的定积分、微分方程、面积体积等全部内容。

### 4.2 核心知识

#### 4.2.1 基本积分公式

必须熟练：

- $\int x^n dx = \dfrac{x^{n+1}}{n+1} + C \quad (n \ne -1)$
- $\int \dfrac{1}{x}dx = \ln|x| + C$
- $\int e^x dx = e^x + C$
- $\int a^x dx = \dfrac{a^x}{\ln a} + C$
- $\int \sin x dx = -\cos x + C$
- $\int \cos x dx = \sin x + C$
- $\int \sec^2 x dx = \tan x + C$
- $\int \dfrac{1}{1+x^2}dx = \arctan x + C$
- $\int \dfrac{1}{\sqrt{1-x^2}}dx = \arcsin x + C$

#### 4.2.2 两大核心方法

不定积分最重要的就是两种方法：

- 换元法；
- 分部积分法。

什么时候优先考虑换元：

- 根号结构明显；
- 复合函数痕迹明显；
- 被积函数里能看到“内函数导数”。

什么时候优先考虑分部：

- 对数函数；
- 反三角函数；
- 多项式乘指数、三角函数；
- 多项式乘对数。

#### 4.2.3 有理函数积分

遇到有理函数时，优先考虑：

- 先化简；
- 真分式拆成部分分式；
- 再按基本积分公式处理。

### 4.3 高频题型

- 直接积分；
- 换元积分；
- 分部积分；
- 有理函数积分；
- 三角函数积分的基本变形。

### 4.4 易错点

- 最后忘记写积分常数 $C$；
- 只换了一半元，没把积分变量彻底换干净；
- 分部积分时选错“谁做 $u$、谁做 $dv$”；
- 看到复杂式子不先化简。

### 4.5 过关标准

- 基本公式能默写；
- 一眼能分出“换元题”还是“分部题”；
- 常见有理函数积分能拆分处理。

## 第五章 一元函数积分学：定积分、反常积分与应用

### 5.1 这一章在解决什么

这一章是把“不定积分的工具”真正用于求值和建模。数学二里定积分既能单独出题，也经常和导数、极限、微分方程联动。

### 5.2 核心知识

#### 5.2.1 定积分基本定理

必须掌握：

- 牛顿-莱布尼茨公式；
- 定积分的线性性质；
- 区间可加性；
- 保号性、比较性、估值。

#### 5.2.2 对称性与换元

这些高频技巧要熟练：

- $\int_{-a}^{a} f(x)\,dx$ 中，奇函数积分为 $0$；
- $\int_{-a}^{a} f(x)\,dx$ 中，偶函数积分可化成 $2\int_{0}^{a} f(x)\,dx$；
- $\int_{0}^{a} f(x)\,dx = \int_{0}^{a} f(a-x)\,dx$。

#### 5.2.3 变上限积分

如果

- $F(x) = \int_{a}^{x} f(t)\,dt$

那么

- $F'(x) = f(x)$。

如果上下限和被积函数都含参，就按莱布尼茨公式思路处理，但一轮阶段先把最基础的变上限求导练熟。

#### 5.2.4 反常积分

要认识两类：

- 积分区间无穷；
- 被积函数在区间端点无界。

一轮阶段重点是：

- 会写出定义；
- 会判断常见反常积分是否收敛；
- 会用换元或比较法处理基础题。

#### 5.2.5 定积分应用

数学二常见应用：

- 平面图形面积；
- 旋转体体积；
- 平面曲线弧长；
- 函数平均值；
- 简单物理应用。

### 5.3 高频题型

- 计算定积分；
- 用对称性简化；
- 变上限积分求导；
- 面积和体积；
- 反常积分收敛性与求值。

### 5.4 易错点

- 忘记先看积分区间是否能用奇偶性；
- 定积分换元后忘记改上下限；
- 面积题忘记绝对值或分段；
- 体积题把“绕哪条轴旋转”看错。

### 5.5 过关标准

- 基础定积分能独立求；
- 对称性技巧能主动想到；
- 面积、体积题知道先画草图再下手。

## 第六章 多元函数微积分学

### 6.1 这一章在解决什么

这是数学二后半程的重点章节。它把一元函数的导数和积分扩展到了二元函数，是很多人一轮里第一次明显卡壳的地方。

### 6.2 核心知识

#### 6.2.1 多元函数、极限、连续

一轮阶段要达到的要求是：

- 了解二元函数的几何意义；
- 知道二元极限与一元极限不同；
- 知道连续函数在有界闭区域上的基本性质。

这部分不需要一开始钻得太深，但不能完全跳过。

#### 6.2.2 偏导数与全微分

必须掌握：

- 一阶偏导；
- 二阶偏导；
- 全微分；
- 多元复合函数求导；
- 隐函数求偏导。

这里最重要的是“层层求导”的意识，不要把二元问题又做回一元问题。

#### 6.2.3 多元极值与条件极值

高频主线：

- 无条件极值：先求偏导，再令一阶偏导为零；
- 条件极值：拉格朗日乘数法；
- 最值问题：结合区域边界一起考虑。

#### 6.2.4 二重积分

二重积分在数学二里是明确主干内容，重点掌握：

- 直角坐标下计算；
- 极坐标下计算；
- 区域的画法；
- 交换积分次序；
- 对称性简化。

看到圆、扇形、圆环这类区域时，要优先考虑极坐标。

### 6.3 高频题型

- 求偏导、全微分；
- 复合函数偏导；
- 隐函数求偏导；
- 求二元函数极值和最值；
- 拉格朗日乘数法；
- 二重积分计算。

### 6.4 易错点

- 偏导时把另一个变量没有当常数；
- 极值题只找驻点，不判断充分条件；
- 二重积分不会先画区域；
- 本来适合极坐标，却硬在直角坐标里算。

### 6.5 过关标准

- 二元函数偏导与全微分题能独立做；
- 极值题知道“先内部、再边界”；
- 二重积分题能先把区域画出来，再决定坐标系。

## 第七章 常微分方程

### 7.1 这一章在解决什么

微分方程是把导数和积分真正串起来的一章。它在数学二里分值不一定最高，但属于“有套路、练熟了就该拿分”的板块。

### 7.2 核心知识

#### 7.2.1 一阶可分离变量方程

标准形式：

- $y' = g(x)h(y)$

核心思路：

- 把含 $y$ 的放一边，含 $x$ 的放一边，再两边积分。

#### 7.2.2 一阶齐次方程

看到

- $y' = F\left(\dfrac{y}{x}\right)$

常用代换：

- 令 $y = ux$，再化成可分离变量。

#### 7.2.3 一阶线性方程

标准形式：

- $y' + p(x)y = q(x)$

核心工具：

- 积分因子 $\mu(x) = e^{\int p(x)\,dx}$。

#### 7.2.4 伯努利方程

标准形式：

- $y' + p(x)y = q(x)y^n$

常见处理：

- 作变量代换，把它化成线性方程。

#### 7.2.5 二阶常系数线性微分方程

重点掌握：

- 齐次情形；
- 非齐次情形的特解结构；
- 特征方程法。

### 7.3 高频题型

- 解一阶可分离变量方程；
- 解一阶线性方程；
- 解伯努利方程；
- 解二阶常系数线性方程；
- 带初始条件求特解。

### 7.4 易错点

- 分离变量时分错边；
- 积分因子写对了，但后面乘法展开错；
- 通解和特解不区分；
- 初值条件代回时计算粗心。

### 7.5 过关标准

- 四类基础方程能识别；
- 看到题目能先判断“它属于哪一型”；
- 能把通解写完整，再代初值求常数。

## 第八章 行列式与矩阵

### 8.1 这一章在解决什么

线性代数一开始最容易让人混乱的地方，是把“行列式”和“矩阵”混成一个东西。你要先分清：

- 行列式是一个数；
- 矩阵是一个表；
- 行列式常用来判断可逆性、求值和做辅助；
- 矩阵才是线代主角。

### 8.2 核心知识

#### 8.2.1 行列式

重点掌握：

- 行列式的定义和基本性质；
- 按行按列展开；
- 利用性质化简计算。

高频性质：

- 交换两行，行列式变号；
- 某行有公因子可以提出；
- 两行相同或成比例，行列式为零；
- 某行加上另一行的倍数，行列式不变。

#### 8.2.2 矩阵基础

必须掌握：

- 矩阵的加减、数乘、乘法、转置；
- 方阵的幂；
- 单位矩阵；
- 逆矩阵；
- 伴随矩阵；
- 初等变换；
- 初等矩阵；
- 矩阵的秩；
- 矩阵等价。

#### 8.2.3 可逆矩阵的常见等价条件

对方阵 $A$，下面这些经常联动出现：

- $A$ 可逆；
- $|A| \ne 0$；
- $r(A) = n$；
- 方程组 $Ax=0$ 只有零解；
- $Ax=b$ 对任意 $b$ 有唯一解。

### 8.3 高频题型

- 求行列式；
- 求逆矩阵；
- 初等变换求秩；
- 解矩阵方程。

### 8.4 易错点

- 把矩阵乘法当对应元素相乘；
- 行变换和列变换混用后忘了自己在做什么；
- 求逆矩阵时不验算；
- 行列式性质和矩阵性质混淆。

### 8.5 过关标准

- 常规行列式计算能稳定完成；
- 会用初等变换求秩和逆矩阵；
- 可逆矩阵几个等价结论能串起来。

## 第九章 向量组与线性方程组

### 9.1 这一章在解决什么

这一章是线代真正的主线。很多看起来分散的内容，最后都能归到两个词：

- 秩；
- 解的结构。

### 9.2 核心知识

#### 9.2.1 向量组

必须掌握：

- 线性组合与线性表示；
- 线性相关与线性无关；
- 极大线性无关组；
- 向量组的秩；
- 向量组的秩与矩阵秩的关系；
- 内积与正交规范化。

#### 9.2.2 线性方程组

最核心的不是“会解一道题”，而是记住解的判定条件：

对非齐次方程组 $Ax=b$：

- 有解 $\Longleftrightarrow r(A) = r(A|b)$；
- 唯一解 $\Longleftrightarrow r(A) = r(A|b) = n$；
- 无穷多解 $\Longleftrightarrow r(A) = r(A|b) < n$。

对齐次方程组 $Ax=0$：

- 只有零解 $\Longleftrightarrow r(A)=n$；
- 有非零解 $\Longleftrightarrow r(A)<n$。

#### 9.2.3 基础解系和通解

如果齐次方程组中：

- 未知数个数是 $n$；
- 矩阵秩是 $r$；

那么基础解系向量个数通常是：

- $n-r$ 个。

这条线代里非常重要，必须熟。

### 9.3 高频题型

- 判断向量组相关无关；
- 求极大线性无关组；
- 判断某向量能否被线性表示；
- 解齐次、非齐次线性方程组；
- 求基础解系和通解。

### 9.4 易错点

- 相关无关只会背定义，不会转成秩或方程组；
- 齐次和非齐次通解结构混乱；
- 消元做了一半，不会从阶梯形读解的结构；
- 自由变量个数写错。

### 9.5 过关标准

- 看到方程组先想到“秩”和“解的判定条件”；
- 能从阶梯形矩阵稳定写出通解；
- 能把向量问题转成矩阵或方程组问题。

## 第十章 特征值、特征向量与相似对角化

### 10.1 这一章在解决什么

这一章看起来抽象，其实核心任务很简单：

- 找特征值；
- 找特征向量；
- 判断能不能相似对角化；
- 利用对角化简化运算。

### 10.2 核心知识

#### 10.2.1 特征值与特征向量

定义来自：

- $Ax = \lambda x$

求特征值的标准步骤：

1. 写特征方程 $|\lambda E - A| = 0$；
2. 解出全部特征值；
3. 对每个特征值解线性方程组 $(\lambda E - A)x = 0$；
4. 求对应特征向量。

#### 10.2.2 相似对角化

矩阵能相似对角化的关键条件是：

- 能找到 $n$ 个线性无关的特征向量。

这时可写成：

- $P^{-1}AP = \Lambda$

对角化后，求 $A^n$ 会容易很多。

#### 10.2.3 实对称矩阵

这是高频重点：

- 不同特征值对应的特征向量正交；
- 一定可以正交对角化。

### 10.3 高频题型

- 求特征值和特征向量；
- 判断矩阵是否可对角化；
- 求 $A^n$；
- 实对称矩阵对角化。

### 10.4 易错点

- 特征值算对了，特征向量解错；
- 重根情形下，没检查线性无关特征向量个数是否够；
- 相似、等价、合同三种关系混淆；
- 结果不验算。

### 10.5 过关标准

- 能完整写出“特征方程-特征值-特征向量”的标准流程；
- 能判断一个矩阵是否可相似对角化；
- 遇到实对称矩阵时知道优先往正交对角化想。

## 第十一章 二次型

### 11.1 这一章在解决什么

二次型本质上是把“矩阵”和“多项式”连起来。它是线代后段的重点，也是很多同学最后才开始真正理解“合同变换”和“正定性”的地方。

### 11.2 核心知识

#### 11.2.1 二次型的矩阵表示

标准形式：

- $f(x) = x^T A x$

其中通常把矩阵写成对称矩阵更方便处理。

#### 11.2.2 标准形与规范形

必须理解：

- 合同变换；
- 合同矩阵；
- 二次型的标准形；
- 二次型的规范形；
- 惯性定理。

#### 11.2.3 化二次型为标准形的方法

考试里最常见两种：

- 配方法；
- 正交变换法。

#### 11.2.4 正定性

判断正定二次型常用两条思路：

- 看对称矩阵的顺序主子式是否都大于零；
- 看特征值是否都大于零。

### 11.3 高频题型

- 写出二次型对应矩阵；
- 配方法化标准形；
- 正交变换化标准形；
- 判断正定性。

### 11.4 易错点

- 非对角项系数和矩阵元素对应关系写错；
- 把合同和相似混了；
- 配方法过程中漏项；
- 正定性判别条件背混。

### 11.5 过关标准

- 二次型和对称矩阵能互相转换；
- 会用配方法化标准形；
- 会用主子式或特征值判断正定性。
